# Nani AI

Nani AI is a care-episode assistant that helps track a patient's care journey from prescription intake through follow-up.

## Getting started

The frontend lives in [client](client).

```bash
cd client
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
